## 1. 问题一：三候选非冷启动分支的未导入函数

### 1.1 缺陷确认（属实）

`backend/app/services/rewrite_candidates.py` 的非 COLD_START 分支第 145 行调用
`usable_style_profile(conn)`，但模块从未导入它。

这是**既有潜伏缺陷**（不是 04-C 引入的）：该行在 04-C 之前就在，04-C 只改了它下面
的 `retriever.find_similar(...)`。之所以一直没暴露，是因为**此前所有三候选测试都在
COLD_START 下跑** —— 那条分支根本没被执行过。

### 1.2 独立复现

把模块命名空间里的 `usable_style_profile` 删掉（等价于"未导入"），在 LEARNING
状态下调用真实的 `generate_candidates()`：

```
state = LEARNING
REPRO NameError -> name 'usable_style_profile' is not defined
```

即：**只要 personalization 离开 COLD_START，三候选生成必然崩溃。**

### 1.3 修复

`backend/app/services/rewrite_candidates.py`：

```python
# 04-C 验收修复 ①：非 COLD_START 分支调用 usable_style_profile(conn)，
# 但本模块**从未导入**它 —— 只要 personalization 进入 LEARNING / PERSONALIZED，
# generate_candidates() 就会抛 NameError。
from app.services.style_profile import usable_style_profile
```

## 2. 问题二：选择参考作者后默认使用其可用画像

### 2.1 变更

`use_reference_profile` 从二态（`bool`，默认 `False`）改为**三态**：

| 值 | 语义 | 缺画像时 |
|---|---|---|
| `None`（**新的默认**） | 选了参考作者 → 就用其**可用**写作画像 | 跳过，记进 `skipped[]`，照常生成 |
| `True` | 调用方**显式**要求必须用 | **明确报错**（保留阶段 7 既有契约与测试） |
| `False` | 明确不用（仅记录来源） | 不注入 |

配套新增 `rewriter.reference_profile_requested()`（唯一判定入口），
`_resolve_reference_profile(conn, author_id, *, strict=...)` 新增 `strict` 参数：
- 作者不存在 → 404，画像与作者不匹配 → 报错（**两条与 strict 无关**）；
- 0 篇已分析内容 → `strict=True` 报错；`strict=False` 返回 `None`。

两个出口（单稿 / 三候选）**共用**同一套语义；新增响应字段
`reference_profile_used: bool`，让"画像是否真的进来了"可被直接观测。

### 2.2 代码差异要点

`backend/app/services/rewriter.py`

```python
# 旧：
if use_reference_profile:
    if reference_author_id is None:
        raise ServiceError("启用作者写作画像时必须提供参考作者")
    reference_profile = _resolve_reference_profile(conn, reference_author_id)
else:
    reference_profile = None

# 新：
if use_reference_profile is True and reference_author_id is None:
    raise ServiceError("启用作者写作画像时必须提供参考作者")

if reference_author_id is not None and reference_profile_requested(use_reference_profile):
    reference_profile = _resolve_reference_profile(
        conn, reference_author_id, strict=use_reference_profile is True,
    )
else:
    reference_profile = None
...
if reference_author_id is not None and reference_profile is None:
    strategy_context["skipped"].append("reference_writing_profile")   # 如实记录
```

`backend/app/services/rewrite_candidates.py` 完全对称。

`backend/app/schemas.py`：`RewriteIn` / `RewriteCandidateIn` 的
`use_reference_profile` 改为 `bool | None = None`；两个 Out 新增 `reference_profile_used`。

前端（`frontend/src/pages/write.tsx`）
- `useProfile` 初值 `false` → **`true`**，切换模式时重置为 `true`；
- 勾选（默认）→ **不传** `use_reference_profile` 字段（让服务端走默认语义）；
  取消勾选 → 显式传 `false`；
- 文案改为「使用作者写作画像（默认开启；取消勾选 = 仅记录来源，仍会用流量与跨作者数据）」。
