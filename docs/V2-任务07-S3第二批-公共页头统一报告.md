## 2. 修改

### 2.1 批量导入（`pages/import.tsx`）

```jsx
<PageHeader
  title="批量导入"
  description={<>支持 JSON / TXT / Markdown / CSV，可一次选择多个文件。导入只入库，
    <span className="text-foreground">不会自动调用 AI</span>，是否分析由你决定。</>}
/>
```

- 说明文字**逐字保留**，包括 `不会自动调用 AI` 的内联强调
- 拖拽区、文件选择、来源选择、解析预览、导入流程**原样未动**

### 2.2 导入记录（`pages/imports.tsx`）

```jsx
<PageHeader
  title="导入记录"
  description="每次批量导入的批次、去重结果与当前占用情况。"
  actions={<Button variant="ghost" size="sm" onClick={() => void load()}>刷新</Button>}
/>
```

- 「刷新」入口的 `variant` / `size` / `onClick` **原样保留**
- 批次列表、记录详情、删除批次、筛选**原样未动**

### 2.3 公共组件（`components/common.tsx`）—— 一处最小扩展

`PageHeader.description` 从 `string` 放宽为 `ReactNode`，并把说明段的 `truncate`
改成**仅对 string 说明生效**：

```jsx
description?: ReactNode
...
<p className={cn("mt-1 text-[13px] text-text-secondary",
    typeof description === "string" && "truncate")}>
  {description}
</p>
```

- **为什么必须放宽**：批量导入的说明里有内联强调，纯 `string` 装不下；
  而「保留原有说明文字」是本轮要求。
- **为什么还要改 truncate**：`truncate` 是单行省略。原说明在 720px 容器里本来就会折到两行；
  若沿用 `truncate`，换成 node 说明后会被截掉一半内容 —— 那是内容损失，不是统一。
- **对既有页面零影响**：三个既有调用方（我的 / 跨作者洞察 / 外部分析）传的都是 string，
  `typeof === "string"` 分支保留了原来的单行截断行为；实测三页 h1 top 与说明行数**逐项不变**。

两页容器 `px-6 py-10` → `px-6 py-8`（顶部间距对齐「我的 / 作者 / 风格档案」；
`max-w-3xl` 宽度按本轮要求**未动**）。
