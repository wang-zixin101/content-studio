## 1. 现状核对（改前实测，`s3_before/measure.json`）

| 页面 | h1 | 字号/字重 | h1 顶部位置 |
|---|---|---|---|
| 作者 | `authors.tsx:108` 手写 | 22px/600 | 34 |
| 风格档案 | `style.tsx:131` 手写 | 22px/600 | **146**（样本统计卡把它顶下去；820px 时 **164**） |
| 我的（参照） | `common.tsx:136 PageHeader` | 22px/600 | 32 |
| 跨作者洞察（参照） | `PageHeader` | 22px/600 | 16 |
| 外部分析（参照） | `PageHeader` | 22px/600 | 32 |

结论：三页手写页头的**字号字重其实已经一致**（都是 22px/600），真正的问题是
①没用公共组件（三处手抄同一串 class，之后会各自漂移）
②风格档案把统计卡放在标题**上方**，标题被推到 146px，与全站「标题在页顶」的节奏不符
③作者页容器 `p-6 md:p-8` 与其它页 `px-6 py-8` 不一致。

## 2. 修改

### 2.1 作者管理（`pages/authors.tsx`）

```jsx
<PageHeader
  title="作者"
  className="mb-6"
  actions={<Button size="sm" onClick={openCreate}>…新增作者…</Button>}
/>
```

- 容器 `mx-auto max-w-4xl p-6 md:p-8` → `mx-auto w-full max-w-4xl px-6 py-8`（与「我的」一致）
- 搜索框、作者列表、编辑 / 删除按钮**原样未动**
- **没有新增说明文字**：原页头本就没有 description，为不擅自编造文案未传该属性
  （`PageHeader.description` 是可选的；要补一句话只需加一行）

### 2.2 风格档案（`pages/style.tsx`）

- `<header>`（h1 + Fingerprint 图标 + 说明 + 更新按钮）→ `PageHeader`
  （title / description / actions 全部沿用原内容）
- **样本统计卡移到标题下方**：`PageHeader` → 统计卡（`mt-6`）→ 状态徽标行（`mt-4`）→ 原正文卡片
  统计项目（有效样本 / 人工原创 / 导入旧作 / AI 辅助后确认 / 排除）、
  说明文字、警示条件（`profile_invalidated_samples`）**逐字保留**
- 「更新风格档案」按钮的 `hasSample` 门控（B3 #49：无可用样本不给 Primary CTA）
  改为 `actions={hasSample ? <Button/> : undefined}` —— 行为不变
- 容器 `px-6 py-10` → `px-6 py-8`（与「我的」一致）
- 去掉标题旁的 Fingerprint 图标：其余三个已用公共页头的页面都没有图标

### 2.3 公共组件（`components/common.tsx`）

**零改动** —— 现有 `PageHeader`（title / description? / actions? / className）足以覆盖两页需求，
没有扩展属性，也没有新建第二套页头。
（sha256 `7376f6f80c5fa53c`，与 S2 完成时一致；`mine.tsx` / `insights.tsx` / `external-analysis.tsx` 三个现有使用方完全未动。）
