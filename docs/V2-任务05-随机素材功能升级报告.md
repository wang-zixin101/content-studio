### 前端：**三处真实缺口**

| # | 缺口 | 证据 |
|---|---|---|
| 1 | **切换作者/素材池后自动抽取** | `material-picker.tsx` 的 `useEffect([pools, pool, poolAuthor])` 立即 `draw()` —— 与「切换作者或素材池后不自动抽取。用户点击「随机抽取」后，才显示一条帖子」直接冲突 |

## 2. 修改内容

### 2.1 新增可测纯逻辑 `frontend/src/lib/material-range.ts`

素材范围与抽取交互的纯函数（无 React / 无网络）：

- `materialRangeOptions(pools, labelOf)` — 全部素材 / 空白作者 / 每个**有素材的**正式作者（count=0 的作者不进列表：点进去必然是死路）
- `rangeTitle()` / `rangeCount()` — 当前范围的可读名字与条数
- `rangeEmptyNotice({title, count, seenCount})` — **点名范围**的抽空提示
- `drawScopeError(pool, authorId)` — `author` 池必须带 `author_id`（与后端同一条规则）
- `drawButtonLabel(hasMaterial)` — 未抽到 = 「随机抽取」，抽到后 = 「换一条」
- `shouldOfferRestart({failed, seenCount})` — 只在抽失败且有已看记录时给「重来」

### 2.2 `frontend/src/components/material-picker.tsx`

- **删除自动抽取 effect**。`draw()` 现在只由用户点击触发。
- **切换范围**（`switchRange`）只做：更新范围 + 清空当前素材 + 清空 `seen` + 清错误，**不抽**。
- **未抽取态**显示「当前范围：X · N 条」+ 一行说明「切换范围不会自动抽取」+「随机抽取」按钮。
- **抽空提示**用 `rangeEmptyNotice` 点名范围，并给出「重来（清空已看 N 条）」。
- **素材卡完整展示 `raw_text`**：`max-h-[26rem] overflow-y-auto`，`whitespace-pre-wrap`，**无 line-clamp、无字符截取**；卡片顶部新增「抽取范围 · X」回显；底部新增字数。
- 按钮文案按规格改为 **「使用这条」**（原「就改这条」），图标从 Shuffle 换成 Check（Shuffle 用在「使用」上语义不对）。

### 2.3 `frontend/src/pages/write.tsx`

- `line-clamp-4` → 可滚动阅读区（已选素材预览）。
- `line-clamp-3` → 可滚动阅读区（已采用来源摘要）。
- 两处都保留 `whitespace-pre-wrap break-words`，换行与段落原样保留。

> 说明：`write.tsx:1323` 还有一处 `line-clamp-3`，那是「参考了你确认过的 N 篇内容」的**横向小卡条**（用户自己作品的 `excerpt`，用于展示风格参考），既不属于「抽取结果展示区域」也不属于「选定素材后的预览区域」，按任务 05 的范围**未改**。

### 2.4 后端测试 `backend/tests/test_regression.py`

只新增测试（11 条），**生产代码零改动**。
