## 2. 修改（`pages/author-detail.tsx`，仅页头块）

```jsx
<div className="border-b border-border px-6 py-4">
  <div className="flex items-start gap-3">
    <Button …asChild><Link to="/library"><ArrowLeft …/></Link></Button>   ← 返回（PageHeader 外侧）
    <PageHeader
      title={displayedName}
      className="min-w-0 flex-1"
      description={有任一元信息 ? (<>@handle / 最近更新 / 备注</>) : undefined}
      actions={<Button …asChild><Link to="/authors">作者管理</Link></Button>}
    />
  </div>
  <div className="mt-4"><Segmented …/></div>
</div>
```

要点：

1. **动态作者名原样保留**（`displayedName`，未改成静态「作者主页」）；
2. **三段元信息逐条保留**：`@username`（B3 #29 条件显示，抽成 `showHandle`）、
   `最近更新 {formatTime(...)}`、`author.notes`（含 `max-w-2xl`）——
   从三个手写 `<p>` 变为 `description` 的 ReactNode（S3 第二批已放宽类型，本批直接复用）；
3. **返回按钮放在 PageHeader 外侧**（它没有前导插槽），按验收要求用轻量 flex 容器包住；
4. **「作者管理」走 PageHeader 的 `actions`**，`variant`/`size`/导航目标不变；
5. **顶部 16px（`py-4`）保留** —— 本页是数据工作台，按你的要求不强改成 32px；
6. 四个标签页、`Segmented`、`border-b`、主体滚动**原样未动**；
7. 三段元信息全都不存在时 `description` 传 `undefined`，不会渲染空 `<p>`。

**`components/common.tsx` 零改动**（`d62f99d2ccba0340`，与 S3 第二批完成时一致）——
没有新建第二套页头，也没有再扩展属性。
