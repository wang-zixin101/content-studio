## 2. 修改

**唯一改动**：15 处 `text-[10px]` → `text-[11px]`。逐处替换，未做任何其它字号、
行高、间距、颜色、字重或结构调整 —— 替换后复查了每个位置的容器：

| 容器情况 | 是否需要调整 | 说明 |
|---|---|---|
| `w-20`(80px) / `w-16`(64px) 右对齐数字 | 否 | 11px 下 "58.4"、"45.2%"、"帖子 6" 均无裁切（实测 `scrollWidth ≤ clientWidth`） |
| `truncate` / `shrink-0` 元素 | 否 | 截断/不收缩语义与字号无关 |
| `source-switch` 的 `<kbd>` | 否 | chip 内 11px，按钮高度不受影响 |
| 侧栏底部模型名 | 否 | 已带 `truncate` |

**没有改动**：`text-xs` / `text-sm` / 13px / 14px 等其它字号（全站 `text-xs`×79、`text-sm`×45 原样）；
未新增字体组件；未改 `tailwind.config.js`。
