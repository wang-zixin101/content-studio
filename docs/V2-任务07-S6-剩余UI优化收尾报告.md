## 1. 已解决问题清单（对照阶段 1 盘点）

| # | 问题 | 处理 |
|---|---|---|
| 1 | **写作页标题 14px**，与全站 22px 不一致 | 页头改用公共 `PageHeader`（个性化徽标 + × 清空进 `actions`，条件与行为不变） |
| 2 | **写作页两个右栏空状态形态不一致**（一个居中带图标、一个左对齐无图标） | 都改用 `EmptyState`（居中、字级统一）；候选空态按 B3 #10 不放图标与按钮 |
| 3 | **4 处原生复选框**（浏览器蓝、圆角不符） | 新增 `ui/checkbox.tsx`（`button[role=checkbox]`，选中态走前景色、4px 圆角、点文字可切换），全部替换 |
| 4 | **解释文案权重过重**（12px secondary、读起来像正文） | 新增 `HelpText`（11px tertiary），应用于外部分析 3 段、批量导入 1 段、写作页素材作者说明 |
| 5 | **导入两页容器 768px** 与其它阅读页 896px 不一致 | `max-w-3xl → max-w-4xl`（宽度对齐；这是阶段 1 遗留的 2 页之差） |
| 6 | **内容库作者 facet 显示裸 username** | `FilterGroup` 支持可选 `label`；页面用既有 `listAuthors` 接口做 `username → display_name` 映射（**不改 API**，过滤仍传 username） |
| 7 | **我的页「导入 CSV」重复**（区块头 + 空状态各一个） | 区块头保留，空状态只留文案指路 |
| 8 | **我的页虚线空状态套在实线面板里**（双层框） | 空状态改 `bordered={false}`，实线面板内不再嵌虚线框 |
| 9 | **跨作者洞察判定规则挤在标题行内**（窄宽度被截断） | 三个分组的规则移到标题下方独立一行的 `HelpText`（共用一个包裹组件，三处同时生效） |
| 10 | **作者管理页图标按钮无可发现性** | 编辑 / 删除图标按钮补 `title` |

### 顺带发现并修复的一个**既有功能缺陷**

验证内容库筛选时发现：点击作者筛选 chip 后 **facets 会重查（只剩王长富）、但列表从不重查**。
根因是 `library.tsx` 列表加载 effect 的依赖数组**漏了 `author` 和 `batchFilter`**
（facets effect 有、列表 effect 没有）—— 即作者筛选与批次筛选一直处于"选了没反应"的状态，
与本批视觉改动无关，属于既有缺陷。修复：补齐依赖。
修复后实测：点击「王长富」chip → 请求变为 `?author_username=wangchangfu&…`、总数 15 → 5。

## 2. 明确**不做**的（避免无必要改动）

| 项 | 原因 |
|---|---|
| 内容库补 h1 页面标题 | 内容库是"筛选列 + 列表列"的工作台，加标题需要重排版面，收益存疑（阶段 1 报告 §4.4 已标注） |
| 内容库行内第三个彩色标签（`参与风格学习`）降灰 | 它已是文本不是徽章；降灰会丢失"这条参与风格学习"的扫读信号，属主观取舍 |
| 写作页候选空态加图标 | B3 #10 明确"不要魔法棒、不要按钮"，保持不放图标 |
| 风格档案结构化档案补全（signature_patterns 等） | 属于功能补全而非视觉优化，超出"局部优化"边界 |
| `/insights` 真实填充态复核 | 受数据阈值限制（同作者内某取值 ≥5 条），合成数据达不到，已在阶段 1 标注 |
